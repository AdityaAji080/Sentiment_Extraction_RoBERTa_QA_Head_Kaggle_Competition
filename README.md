This project implements a RoBERTa-based Question Answering (QA) model for sentiment extraction. The model reformulates sentiment analysis as a span-extraction task, where given an input text (e.g., a tweet) and a prompt identifying the sentiment to be located, RoBERTa predicts the start and end positions of the sentiment-bearing phrase. During fine-tuning, the model learns to align its predicted spans with the annotated “selected_text” segments using cross-entropy loss over start and end logits. At inference, the predicted token indices are mapped back to the original text to extract the exact sentiment span. This approach leverages RoBERTa’s deep bidirectional contextual understanding to precisely localize and interpret nuanced emotional expressions within text, rather than assigning a single global sentiment label.
